# 🍕 Pizza Billing System

A Java-based console application for generating pizza bills based on the user's choices.

## 📌 Project Description

The Pizza Billing System allows users to select different types of pizzas and calculates the total bill according to their selections.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Scanner Class

## 📂 Project Files

| File | Description |
|------|-------------|
| `Main.java` | Main program and user input |
| `Pizza.java` | Pizza class and common pizza features |
| `DeluxPizza.java` | Deluxe pizza functionality |

## ✨ Features

- Normal Pizza
- Deluxe Pizza
- Veg Pizza
- Non-Veg Pizza
- Automatic bill calculation
- User-friendly console interface

## ▶️ How to Run

### 1. Compile the Java files

`javac Main.java Pizza.java DeluxPizza.java`

### 2. Run the program

`java Main`

## 💻 Sample Output

    1. Normal Pizza
